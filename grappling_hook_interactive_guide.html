O tomto průvodci

Tato aplikace vás provede vytvořením plně funkčního základu pro přitahovací hák. Systém umí vystřelit vizuální lano, detekovat povrch a následně buď přitáhnout hráče ke zdi, nebo strhnout fyzikální krabici k hráči. Postupujte podle kroků níže.

⚡ Než začneme (Předpoklady)

  • Výchozí projekt: Začínáme s čistým Third Person template projektem (doporučeno mít zapnutý Starter Content kvůli testovacím krabicím).
  • Verze Enginu: Tutoriál je napsán a testován přímo na míru pro Unreal Engine 5.6.1.
  • Důležité upozornění: Epic Games mezi verzemi často přejmenovává uzly (nodes) nebo přesouvá položky v panelu Details. Pokud používáte novější verzi, může se stát, že se nějaký uzel bude jmenovat mírně jinak (např. Set End Location se v jiných verzích jmenuje Set Custom End Location). Zachovejte chladnou hlavu, základní principy Blueprintů se nemění!
